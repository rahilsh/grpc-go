# Support

This project is maintained as a set of learning examples and has no commercial
support or service-level agreement.

- Read the [README](README.md) for setup and usage.
- Search existing [issues](https://github.com/rahilsh/golang-lab/issues) before
  opening a new one.
- Use the bug report template for reproducible defects.
- Ask general gRPC questions in the official
  [gRPC community](https://grpc.io/community/).

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
